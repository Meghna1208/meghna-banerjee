# Meghna Banerjee — Portfolio

Personal portfolio for Meghna Banerjee, AI intern and B.Tech student at RCC Institute of Information Technology. It's a single scrolling page with an introduction, experience, projects (SwarSanket, Airnexa), skills, certifications, education and a contact form. It also links to her GitHub, LinkedIn, email and a downloadable CV.

## Tech

- TanStack Start (React 19) + Vite
- Tailwind CSS 4
- Netlify Forms for contact form submissions
- Deployed on Netlify

## Run locally

```bash
pnpm install
netlify dev     # or: pnpm dev
```

## Updating content

All text, links and lists live in `src/data/profile.ts`. To replace the downloadable CV, overwrite `public/Meghna_Banerjee_CV.pdf`.
